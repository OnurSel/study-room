# Scope

## In (v1)
- Anonymous join with a display name; rooms by short code.
- One shared Pomodoro timer per room (work / break / long break).
- Live presence of everyone in the room.
- Shared task list with live updates.
- Reconnect with full state resync.
- Basic abuse limits.

## Out (v1, on purpose)
- Accounts, passwords, email.
- Chat, voice, video, screen sharing.
- Native mobile apps (the web client must simply work on a phone).
- Payments, analytics, ads.
- Persistence of rooms beyond a short TTL (only finished-session summaries are stored).

## Rules for changing scope
Anything new needs a written reason and must not delay a phase's exit criterion.
